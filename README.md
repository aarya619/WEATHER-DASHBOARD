#  Modern Weather Dashboard

A responsive, feature-rich weather application built with React and Vite. This app allows users to search for global cities and instantly view real-time weather conditions, interactive temperature trends, and dynamic maps.

# Features
* **Live Weather Data:** Instantly fetches current temperature, humidity, wind speed, and "feels like" metrics.
* **5-Day Forecast Chart:** Visualizes upcoming temperature trends using Chart.js.
* **Interactive Map:** Pinpoints the searched city using Leaflet.
* **Smart Search:** Includes a search history memory for quick access to recently viewed cities.
* **Dynamic UI:** Glassmorphism design with responsive grid layouts that look great on desktop and mobile.
* **Error Handling:** Gracefully handles invalid city searches with user-friendly alerts.

## Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Data Visualization:** Chart.js, React-Chartjs-2
* **Maps:** Leaflet, React-Leaflet
* **API:** OpenWeatherMap API

##  How to Run Locally
1. Clone the repository.
2. Run `npm install` to install all dependencies.
3. Create a `.env` file in the root directory and add your API key: `VITE_WEATHER_API_KEY=your_api_key_here`
4. Run `npm run dev` to start the local server.
