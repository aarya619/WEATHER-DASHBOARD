# 🌦️ Weather Dashboard

A modern and responsive weather application built with **React**, **Vite**, and **Tailwind CSS**. It provides real-time weather information, detailed forecasts, interactive charts, and location-based insights through a clean and intuitive interface.

---

## ✨ Features

* 🌍 Search weather for any city around the world
* 🌡️ Live temperature, feels-like temperature, humidity, and pressure
* 💨 Wind speed and wind direction details
* ☁️ Weather conditions with dynamic icons
* 📅 5-Day weather forecast
* 📊 Interactive temperature trend charts
* 🗺️ Interactive map powered by Leaflet
* 🕒 Recent search history
* 📱 Fully responsive design for desktop, tablet, and mobile
* 🌙 Beautiful modern glassmorphism-inspired UI
* ⚡ Fast loading experience with Vite
* 🚨 User-friendly error handling for invalid locations

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/weather-dashboard.git
```

### 2️⃣ Move into the Project

```bash
cd weather-dashboard
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Create Environment File

Create a `.env` file in the project root and add:

```env
VITE_OPENWEATHER_API_KEY=YOUR_API_KEY
```

### 5️⃣ Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
